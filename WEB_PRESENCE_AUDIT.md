## 12. Methodology & limitations

### What was done

- Multiple targeted web searches across Google-indexed results
- Extraction of URLs, titles, snippets, and roles from search syntheses
- Cross-grouping by platform and homonym analysis
- Alignment notes against DS ontology (Framework → practices → Enlystnow → 18 doors)

### What was not done (gaps)

- **Bright Data SERP API** returned 401 — no paginated Google deep crawl
- **No live browser session** visiting every URL (some pages may have changed since index)
- **No exhaustive LinkedIn employee scrape** (LinkedIn limits public indexing)
- **No Wayback Machine** historical diff
- **No paid database** pulls (ZoomInfo, Apollo, RocketReach company records not retrieved)
- **Instagram/Facebook** may exist but were not verified by direct fetch

### Confidence key

| Label | Meaning |
|-------|---------|
| **Confirmed** | Multiple independent sources or official domain |
| **Likely** | Single reputable directory or LinkedIn-only |
| **Homonym** | Same name, different entity — do not merge |
| **Unverified** | Mentioned in search synthesis only; URL not opened |
