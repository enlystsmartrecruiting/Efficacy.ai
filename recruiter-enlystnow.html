    How to use this workspace

    Operator guide, storage, and the path to Indeed-class hiring — all in one place.

    Quick start (5 minutes)

    Open Job board to see published reqs. Click Apply to simulate a candidate; the person appears under Applications and as Sourced in Pipeline.

    Use Talent pool for search across people; open a profile and Advance stages as you would in a full ATS.

    Storage & backup

    Data lives in localStorage on this browser. Use Settings → Export backup before clearing cache or switching machines. Import restores a prior snapshot.

    • Not suitable for regulated PII at scale until you add a backend (see roadmap file).
    • Typical limit ~5 MB per site origin.
