09 — minimum usage rules
✓ Do
Use the horizontal lockup as default in all navbars, documents, and presentations. The mark and wordmark must always appear together unless space prevents it.
✗ Don't
Never stretch, rotate, recolour, or add effects to the mark. Never use the dark-background wordmark on a light surface, or vice versa.
✓ Do
Use the icon mark alone when the full lockup is below 120px wide. Use the favicon variant in browser tabs, app icons, and social profile photos.
✗ Don't
Never use one division's colour with another division's wordmark. Never use Instrument Serif for the enlysoft wordmark — it must always use DM Mono.
✓ Do
Each division is colour-exclusive: Blue = enlyst, Green = enlysum, Amber = enlybiz, Purple = enlysoft. Maintain this mapping in all materials.
✗ Don't
Never use the consumer-facing division names (enlyst, enlysum, etc.) in legal documents. Use "Enlyst Smart Recruiting Pvt Ltd" for all legal purposes only.
